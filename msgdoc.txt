docs: record the four-terminal start and the real-browser verification

Everything below is what we just ran, written down so it does not have to be rediscovered.

runbook 3c — daily start, four terminals: zitadel port-forward, `pnpm dev`, edge, client.
Infra needs none: it is reached over NodePorts. The two failures that look like
application bugs are recorded with their real causes, because both cost real time:

  - storefront `Error: HTTP 400` + edge "resolve-slug upstream unreachable" + API log
    "port 3000 is busy" -> a stale API from an earlier session owned the port, so the edge
    and the browser were talking to a process with old env. Kill by command line.
  - login 500 with `ECONNREFUSED` -> the zitadel port-forward was missing.

runbook 3d — verify with a real browser: `pnpm smoke:browser` drives installed Chrome
through playwright-core (already in the pnpm store), visibly rather than headless, and
walks the same chain a person does: storefront renders, seeded product renders with its
price, login form exists, login leaves /login, admin dashboard renders, no 5xx and no
console errors.

Why a browser and not only HTTP checks, stated as the finding it was: the HTTP checks all
passed while the page was rendering "Error: HTTP 400". A script proves the hops exist; a
browser proves a person can use it.

runbook 3e — why exactly one port-forward stays. ZITADEL_ISSUER is the `iss` claim inside
every token, and WSL renumbers the node on every reboot, so a NodePort would mean a
re-identity per reboot plus hostAliases in every pod that break with the IP. `localhost`
never moves. One process per session beats a recurring identity ceremony — and in staging
the issuer is a real DNS name, so even that disappears.

scripts/smoke-browser.mjs is committed as the executable form of 3d, exposed as
`pnpm smoke:browser`. Deliberately NOT added to scripts/k8s.mjs: it needs host processes
(edge, client), so it is not a cluster concern. Screenshots are gitignored.

Verified on the clean start: all four processes ready, `pnpm smoke:browser` -> ALL PASS
(8 checks).
