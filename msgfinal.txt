refactor(edge): take the edge out of the cluster and collapse three docs into one

The edge ran inside k8s for a while and worked, but it needed three workarounds to get
there - and three workarounds is the signal that the placement is wrong:

  - a socat sidecar, because inside a pod `localhost:8080` is the pod
  - `--var API_ORIGIN`, because `wrangler dev` reads vars from wrangler.toml, not
    container env
  - a seeded emulated R2 bucket, because the SPA is served from R2 and nothing uploads
    it outside `wrangler deploy` (this was the 503)

It also cost 3-5 minutes per change (build -> save -> import -> rollout) against seconds
with `wrangler dev`. The edge is a Worker: host in dev, Cloudflare in production. The
cluster is the origin.

Removed: deploy/edge/ (Containerfile, entrypoint.sh, deployment.yaml), the edge checks in
`status`, the edge build and rollout in `up`, and the half-finished `dev` verb - that verb
only existed to tunnel into a cluster-hosted edge, which is no longer the shape.

CLI is now purely the parity tool: up | status | identity | pull | seed | down.

Docs: EDGE-DEPLOYMENT-DECISION, EDGE-ARCHITECTURE-ANALYSIS and EDGE-PLATFORM-COMPARISON
overlapped and two of them predated the decision, so they are replaced by one EDGE.md
stating the rule up front:

  daily dev   compose + pnpm dev + wrangler dev
  parity      k8s origin, edge still on the host
  production  Cloudflare Workers + k8s origin

It keeps the parts that were expensive to work out: the inventory of what the edge does
beyond auth, the R2-upload 503 trap, the Lambda@Edge limits that rule it out (no env vars,
no WebSocket events, 40 KB body truncation), and the cheap in-cluster path if an
air-gapped target ever appears.

Runbook relabelled so nobody mistakes the parity script for the daily loop: banner, the
scope line in section 1, the layout table (client's /api points at a HOST-run edge), and
the gaps table. Tracker steps 10 and 12 updated to match.

Verified: `node scripts/k8s.mjs status` -> 16 checks, no edge, all green, exit 0.
