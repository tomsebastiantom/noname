# Build with Noname

Noname is an AI-native, declarative full-stack platform. Describe what you want, represent it as a spec, and execute it across UI, backend machines, integrations, and vertical extensions.

## Choose a path

- **[Build your first store](get-started/build-your-first-store)** — complete the first working journey.
- **[Set up local development](get-started/local-development)** — start the local stack and understand the repository.
- **[Create an extension](how-to/create-an-extension)** — add domain-owned product behavior.
- **[Understand the architecture](concepts/system-overview)** — learn the platform boundaries.
- **[Read the API reference](reference)** — look up exact generic contracts.

## Documentation types

This site follows Diátaxis:

- **Tutorials** teach a complete journey.
- **How-to guides** solve one practical task.
- **Concepts** explain how and why the system works.
- **Reference** documents exact contracts.

Historical implementation records and audit reports are kept under [History](history/overview), not mixed into the learning path.
