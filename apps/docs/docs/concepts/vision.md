# The Noname vision

Noname is building a reusable platform for a world where software is shaped by people and agents together.

## Who we are

We are not building one closed vertical product. We are building a foundation that lets teams turn intent into working products without rebuilding the same identity, content, UI, workflow, integration, and audit primitives every time.

Commerce is our first demanding proving ground. It makes the platform prove trusted pricing, durable workflows, provider boundaries, customer-facing interfaces, and auditable outcomes. The foundation is deliberately broader than Commerce.

## What we believe

- **Intent should be executable.** A clear product idea should become a reviewable specification, not disappear into disconnected tickets and glue code.
- **Agents should collaborate, not replace judgment.** People set goals, constraints, and acceptance. Agents propose, explain, implement, and learn from feedback.
- **The foundation should be reusable.** Identity, documents, layouts, permissions, machines, capabilities, integrations, and provenance should serve many products.
- **The system should remain inspectable.** Open source, explicit decisions, durable evidence, and readable contracts make powerful automation trustworthy.

## The future we are building

```text
person expresses intent
  → agent proposes a spec and plan
  → person reviews, edits, and approves
  → platform runs the same contract
  → product returns evidence and feedback
  → person and agent improve it together
```

## What Noname is becoming

A reusable application substrate where a team can say:

> “This is the product we want. These are the rules and constraints. Help us shape it, run it, and keep it understandable.”

Then the platform provides the shared runtime while the team owns its domain and experience.
